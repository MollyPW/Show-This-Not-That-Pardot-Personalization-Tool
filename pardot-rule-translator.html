Describe your if/then logic below. This tool tells you exactly which native Pardot feature builds it, gives you the click-by-click setup, and generates a full QA test matrix — every prospect profile you need to test, and what should render for each.

ⓘ Why doesn't this generate Apex code?
Apex only runs on Salesforce's servers — it has no way to execute inside a Pardot email's WYSIWYG editor, so pasted Apex would just show up as plain text to recipients. The two things that actually do run in an email are Dynamic Content (Pardot's built-in, point-and-click rule builder — supports "equals," "contains," and number comparisons like "greater than") and HML (Handlebars Merge Language — a few lines of code pasted into the HTML source, but it can only check whether a field has any value, not compare it to a specific number or word). This tool routes you to whichever one actually fits your rule.
